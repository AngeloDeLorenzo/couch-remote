Couch Remote

GTK remote control for Android TV and Google TV devices on the local network.

Install via Flatpak

Your browser may ask to open the file with your software center. If nothing happens, use the commands below.

Install from the terminal

flatpak install --user https://angelodelorenzo.github.io/couch-remote/couch-remote.flatpakref

This installs the app and sets up this repository as its origin, so future versions arrive with a normal update.

Keep it up to date

flatpak update

Add only the repository (without installing)

flatpak remote-add --user --if-not-exists couch-remote \
  https://angelodelorenzo.github.io/couch-remote/couch-remote.flatpakrepo
flatpak install --user couch-remote io.github.angelodelorenzo.couch-remote

The app needs the org.gnome.Platform runtime, which Flatpak pulls from Flathub on first install.

Source code and bundles: github.com/AngeloDeLorenzo/couch-remote
This repository is GPG-signed; the key is embedded in the .flatpakref / .flatpakrepo files.
